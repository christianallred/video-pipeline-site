Video Pipeline

A personal video production pipeline for a few small YouTube channels.

Video Pipeline is a self-hosted tool that runs on one PC. It keeps each video's plan, footage, edits, review notes, thumbnail and YouTube details in one place. A phone-friendly web app shows where every video stands. When a video is finished and approved, the app can upload it, with its title, description, tags and thumbnail, to the owner's own YouTube channel.

Channels that use it

  • Secret Garden Woodshop: woodworking and shop builds
  • Second Hand Watches: watch repair and builds
  • Measure Once Pour Twice

YouTube access

The app uses the YouTube Data API only to upload the channel owner's own videos and thumbnails to their own channels, and to read the channel's name so it shows which channel is connected. See the privacy policy.
